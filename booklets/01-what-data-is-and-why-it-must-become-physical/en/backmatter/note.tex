This booklet has emerged from an open-source repository that never truly
comes to an end. If part of this booklet is still marked as ``in progress,''
it may have been completed by the time you read these pages; and other
booklets from this volume, which had not yet been written on the day this
edition was printed, may now exist.

What you are holding is itself an example of what this booklet is about:
an abstract representation a text that lives in a Git repository as a
sequence of bytes that has ultimately been transformed, through ink and
paper, into a physical and fixed signal. The repository is still changing;
this edition, from the moment it is printed, will not.

If you want to see how far the work has progressed since this edition was
printed, the project repository, unlike these pages, is still alive:

\begin{center}
\url{https://github.com/papyrxis/arliz}
\end{center}

This edition, \BookletEdition\ of \BookletYear, remains fixed here forever.
The rest of the journey continues elsewhere.
